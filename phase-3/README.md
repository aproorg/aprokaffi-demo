# Phase 3 — Reusable implementation skill

Start from the completed phase 2 snapshot.

Create a skill that reads the prepared Jira ticket through the Jira MCP and implements the requested change. The skill makes the direct flow reusable.

## How this was generated

This was generated by prompting, from [phase 2](../phase-2/README.md):

> Could you please create a skill that helps me implement a feature. The skill should read
> a supplied jira ticket information and implement it. Focusing on keeping to scope,
> following existing patterns in the code, and creating tests for the new feature
> (including endpoint tests and service tests).

## Try it yourself

If you want to see how we evolved to [phase 4](../phase-4/README.md), you can try
prompting:

> Now I want to expand my claude setup by creating a subagent that should handle the
> implementation. The subagent should be called implementation-agent. It should be invoked
> on a hiku model to save on token cost. It should read the jira ticket and then use that
> information to invoke the /implement-jira-ticket skill.
