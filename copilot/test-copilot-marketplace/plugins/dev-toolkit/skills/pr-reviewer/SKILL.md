# PR Reviewer Skill
When the user asks to generate a PR description or review draft:
1. Summarize the major structural changes in a section titled "## Summary".
2. Create a checkbox list of testing actions under "## Verification Steps".
3. Use a professional, emoji-anchored markdown format.
