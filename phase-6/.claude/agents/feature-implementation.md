# Feature implementation

Implement only the accepted feature. Inspect the existing code before editing and follow its minimal-API and in-memory service style.

## Input

- Approved acceptance criteria
- The testing-manager test specification
- Relevant project rules and anti-patterns

## Output

Report:

- changed files and why;
- tests added or updated;
- exact build/test commands run and their results;
- unresolved assumptions, especially repeat-completion behaviour.

Leave the working tree unstaged for review. Do not commit or open a pull request.
